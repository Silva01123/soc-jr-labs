# 🧪 Linux Lab 04 – Log Analysis

## Objective

Investigate Linux system logs to identify authentication events, administrative activity, and potential suspicious behavior using `journalctl` and log filtering techniques.

---

## Scenario

The monitoring team reported multiple authentication events on a Linux server during the early hours of the morning.

As a SOC Analyst, the objective was to review system logs, identify authentication attempts, verify administrative activity, and determine whether any suspicious actions had occurred.

---

## Tools & Commands Used

* `journalctl`
* `journalctl -n 50`
* `journalctl | grep sudo`
* `grep`

---

## Investigation Steps

### 1. Initial Log Review

Executed:

```bash
journalctl -n 50
```

Reviewed:

* Recent system events
* General system activity
* Service logs

**Result:**

The initial output contained various system events generated by different services, making it difficult to focus on authentication-related activity.

---

### 2. Log Filtering

Executed:

```bash
journalctl | grep sudo
```

Reviewed:

* Administrative authentication events
* Successful and failed `sudo` attempts
* Commands executed with elevated privileges

**Result:**

The filtered output displayed only events related to `sudo`, allowing a focused investigation of administrative activity.

---

### 3. Authentication Analysis

The investigation identified multiple authentication failures:

```text
pam_unix(sudo:auth): authentication failure
```

These events indicated unsuccessful attempts to authenticate with `sudo`.

---

### 4. Successful Administrative Sessions

The logs also showed successful administrative sessions:

```text
pam_unix(sudo:session): session opened for user root
```

These entries confirmed that `sudo` authentication later succeeded.

---

### 5. Command Execution Review

The logs recorded the commands executed with elevated privileges, including:

* `whoami`
* `ls -l /proc/...`
* `ss -tulpn`

All commands were consistent with legitimate administrative and investigation activities.

---

## Findings

* Multiple failed `sudo` authentication attempts were identified.
* Successful administrative sessions were established after authentication.
* Commands executed with elevated privileges were legitimate.
* No suspicious or unauthorized administrative activity was observed.

---

# Conclusion

The investigation confirmed that the authentication failures were followed by successful administrative sessions using legitimate credentials.

The commands executed with elevated privileges were consistent with authorized system administration and security investigation tasks.

Based on the collected evidence, no indicators of malicious activity or unauthorized privilege abuse were identified.
