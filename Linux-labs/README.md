# 🐧 Linux SOC Analyst Labs

This repository contains hands-on Linux investigation labs focused on the daily activities of a Junior SOC Analyst. Each lab simulates real-world scenarios involving process analysis, user investigation, network inspection, log analysis, persistence detection, and incident response.

## Objective

The goal of these labs is to develop practical Linux investigation skills required for a Security Operations Center (SOC) role, including:

* Linux process analysis
* User and privilege investigation
* Network connection analysis
* Log analysis using system logs and journalctl
* Service and persistence detection
* File system and IOC hunting
* Incident correlation
* Incident documentation and reporting
