# SIEM Labs — SOC Analyst Jr

## Overview

This section documents Security Information and Event Management (SIEM) labs focused on security monitoring, alert triage, event investigation, event correlation, and incident analysis.

## Tools

- Wazuh
- Windows Security Events
- Security logs and investigation data

## Learning Objectives

- Understand Wazuh alerts and events.
- Investigate Windows authentication activity.
- Correlate related security events.
- Analyze suspicious processes and network activity.
- Identify indicators of compromise (IOCs).
- Document findings and recommend appropriate actions.

## Wazuh Labs

The Wazuh labs are organized around practical SOC Analyst Jr investigation scenarios. Each lab documents its environment, data sources, investigation steps, evidence, findings, and conclusion.

**Evidence Integrity:** Each lab identifies whether the evidence comes from a real Wazuh environment or from a simulated investigation dataset. Simulated results are not presented as real Wazuh alerts.
