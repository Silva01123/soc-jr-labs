# Wazuh — SOC Analyst Jr Labs

## Objective

Develop practical skills in Wazuh-based security monitoring, alert triage, event investigation, correlation, threat detection, and incident reporting.

## Scope

These labs follow a structured SOC Analyst Jr learning roadmap, prioritizing detection and investigation over advanced Wazuh administration.

## Investigation Workflow

Alert → Context → Event Analysis → Evidence Collection → Correlation → IOC Analysis → MITRE ATT&CK Mapping → Classification → Recommended Action → Report

## Lab Index

| Lab | Title | Focus |
|---|---|---|
| 01 | Failed Login Investigation | Windows authentication failures |
| 02 | Brute Force Detection | Repeated authentication attempts |

Additional labs will be documented as they are completed.

## Methodology

Each lab includes a scenario, objectives, data sources, investigation procedure, evidence, findings, and conclusion.

The environment and evidence type are explicitly documented. Simulated investigations are distinguished from investigations performed in a running Wazuh environment.
