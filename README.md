Hands-on SOC Analyst labs focused on developing practical blue team and incident investigation skills through realistic scenarios.

* Windows Investigation
* Event Log Analysis
* Process Investigation
* Registry Analysis
* User & Privilege Investigation
* Network Investigation

* Incident Response

### Linux

* Process Investigation
* User & Privilege Investigation
* Network Investigation

* Incident Correlation
* Full SOC Investigation

## Objective

This repository documents my practical journey toward becoming a SOC Analyst through hands-on defensive security labs based on realistic incident scenarios.

The labs cover both Windows and Linux environments, focusing on the investigation techniques used by Security Operations Center (SOC) analysts. Topics include process analysis, user and privilege investigation, network activity, log analysis, persistence detection, IOC hunting, service analysis, incident correlation, and technical reporting.

The goal is to build practical investigation skills, strengthen analytical thinking, and create a professional portfolio that reflects real-world SOC workflows rather than only theoretical knowledge.
