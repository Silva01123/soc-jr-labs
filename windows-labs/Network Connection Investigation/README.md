# Network Connection Investigation Lab

## Objective

Investigate active network connections on a Windows system and correlate them with running processes.

## Tools Used

- Command Prompt (CMD)
- PowerShell
- netstat -ano
- tasklist
- Get-NetTCPConnection

## Investigation

Several websites were opened in Google Chrome to generate network traffic.

The following commands were used during the investigation:

```cmd
netstat -ano
```

```cmd
tasklist | findstr <PID>
```

```powershell
Get-NetTCPConnection -State Established | Select-Object -First 10
```

An active TCP connection in the ESTABLISHED state was identified.

The connection details included:

- Remote Port: 443 (HTTPS)
- State: Established
- PID: 8272

The PID was correlated with a running process using the tasklist command.

The investigation confirmed that PID 8272 belonged to:

```text
chrome.exe
```

PowerShell was used to review additional established connections and identify the associated process IDs.

## Results

- Active TCP connections were successfully identified.
- Multiple HTTPS connections were observed.
- PID 8272 was correlated with chrome.exe.
- Established connections were consistent with normal web browsing activity.
- No suspicious processes or network activity were detected.

## Conclusion

A network connection investigation was successfully performed using CMD and PowerShell.

Active connections were analyzed and correlated with running processes through PID identification.

The investigation confirmed legitimate HTTPS traffic generated by Google Chrome, and no indicators of malicious activity were identified.
