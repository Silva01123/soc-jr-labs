# Failed Login Investigation Lab

## Objective

Investigate failed login attempts in Windows using Event Viewer and Security Logs.

## Tools Used

* Event Viewer
* Windows Security Log
* Event ID 4625

## Investigation

A failed login event was generated by intentionally entering an incorrect password on the Windows login screen.

The Security log was accessed through Event Viewer and filtered for Event ID 4625.

A total of 6 failed login events were identified.

One event was selected for analysis.

The investigation identified:

* User: Sant'Ana
* Computer: PAVILIONHPVS
* Logon Type: 2 (Interactive)
* Failure Reason: Unknown username or incorrect password
* Status: 0xC000006D
* Substatus: 0xC000006A
* Source Address: 127.0.0.1
* Process: svchost.exe

## Results

The failed login attempt originated from the local machine.

The logon type indicated an interactive login through the Windows login screen.

The failure was caused by an incorrect password.

The process involved was a legitimate Windows process located in System32.

No suspicious activity was identified.

## Conclusion

A Windows failed login investigation was successfully performed using Event Viewer and Security Logs.

The Event ID 4625 was analyzed to identify the affected user, authentication failure reason, logon type, source address, and associated process.

The investigation concluded that the events were legitimate failed login attempts with no indicators of malicious activity.
