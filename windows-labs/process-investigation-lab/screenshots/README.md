# Process Investigation Lab

## Overview

This lab focuses on basic process investigation techniques in Windows. The objective was to identify running processes, analyze system activity, and understand how different Windows tools can be used during a security investigation.

## Tools Used

* Task Manager
* tasklist
* Get-Process
* netstat

## Investigation Steps

1. Reviewed running processes using Task Manager.
2. Listed active processes with the `tasklist` command.
3. Investigated processes using PowerShell with `Get-Process`.
4. Checked active network connections using `netstat`.
5. Correlated process information with network activity.

## Findings

The investigation provided visibility into running applications, process identifiers (PIDs), and active network connections. This helped build a foundational understanding of how security analysts identify suspicious processes and validate system activity.
